# OpenHands LLM 模块架构

## 概述

OpenHands LLM 模块是整个 OpenHands 系统的核心组件，负责与各种大型语言模型（LLM）进行交互。该模块提供了统一的接口来处理不同的 LLM 提供商，支持同步、异步和流式调用。它还包含了重试逻辑、函数调用转换、指标收集、调试功能、成本跟踪和多模态内容处理等高级功能。

## 技术栈

- **Python 3.12+**：核心编程语言
- **LiteLLM**：统一的 LLM API 接口库，支持多种 LLM 提供商
- **Pydantic**：用于数据建模和验证
- **Asyncio**：用于异步操作和并发处理
- **Tenacity**：用于实现重试机制和错误恢复
- **HTTPx**：用于 HTTP 客户端通信
- **Functools**：用于函数装饰器和偏函数
- **Warnings**：用于警告处理和过滤
- **混入模式（Mixin Pattern）**：用于代码复用和功能组合
- **装饰器模式**：用于增强函数功能
- **工厂模式**：用于创建不同类型的 LLM 实例

## 核心组件

### 1. LLM 基础类 (LLM)

`LLM` 类是与语言模型交互的主要入口点。它：

- 处理与 LLM 提供商的通信
- 支持各种模型配置参数
- 处理函数调用的转换
- 收集使用指标和成本信息
- 实现重试逻辑和调试功能

### 2. 异步 LLM (AsyncLLM)

`AsyncLLM` 类继承自 `LLM` 类，提供异步接口与 LLM 交互。它：

- 支持异步调用 LLM API
- 处理异步上下文中的取消操作
- 维护与基础 LLM 类相同的功能集

### 3. 流式 LLM (StreamingLLM)

`StreamingLLM` 类继承自 `AsyncLLM` 类，专门用于处理流式响应。它：

- 支持流式输出，逐步返回 LLM 生成的内容
- 在流式传输过程中处理取消操作
- 为每个流式块收集指标

### 4. 函数调用转换器 (fn_call_converter)

该模块负责在支持和不支持函数调用的模型之间进行转换。它：

- 将函数调用消息转换为普通文本提示
- 将普通文本响应解析回函数调用格式
- 提供示例和模板以增强模型理解

### 5. 重试混入类 (RetryMixin)

`RetryMixin` 类提供了重试逻辑，用于处理 LLM API 调用中的临时错误。它：

- 使用指数退避策略进行重试
- 支持自定义重试参数
- 记录重试尝试和错误信息

### 6. 调试混入类 (DebugMixin)

`DebugMixin` 类提供了调试功能，用于记录 LLM 交互。它：

- 记录发送到 LLM 的提示
- 记录从 LLM 接收的响应
- 格式化多模态内容以便于调试

### 7. 指标收集 (Metrics)

`Metrics` 类负责收集和管理与 LLM 使用相关的各种指标。它：

- 跟踪 API 调用成本
- 记录响应延迟
- 统计令牌使用情况
- 支持指标合并和差异计算

## 数据流

1. **基本 LLM 调用流程**:
   - 应用程序创建 LLM 实例并配置参数
   - 应用程序准备消息并调用 LLM 的 completion 方法
   - LLM 类处理消息格式化和函数调用转换
   - LLM 类调用 LiteLLM 与实际的 LLM 提供商通信
   - LLM 类处理响应，收集指标，并返回结果

2. **异步调用流程**:
   - 应用程序创建 AsyncLLM 实例
   - 应用程序异步调用 async_completion 方法
   - AsyncLLM 在异步上下文中处理请求
   - 结果通过 asyncio 机制返回

3. **流式调用流程**:
   - 应用程序创建 StreamingLLM 实例
   - 应用程序异步迭代 async_streaming_completion 方法的结果
   - StreamingLLM 逐块产生响应
   - 应用程序处理每个响应块

4. **函数调用转换流程**:
   - 检查模型是否原生支持函数调用
   - 如果不支持，将函数调用消息转换为文本提示
   - 发送转换后的提示到 LLM
   - 解析响应，将文本转换回函数调用格式

## 配置选项

LLM 模块支持多种配置选项，包括：

- **模型选择**：指定要使用的 LLM 模型
- **API 凭证**：提供访问 LLM API 所需的密钥
- **生成参数**：温度、top_p、top_k 等控制生成过程的参数
- **重试设置**：重试次数、等待时间和重试条件
- **函数调用支持**：启用或禁用函数调用功能
- **视觉功能**：支持多模态输入，包括图像
- **安全设置**：控制模型输出的安全参数

## 支持的模型

LLM 模块支持多种模型，包括：

- **Claude 系列**：Claude 3 Opus、Sonnet、Haiku 等
- **GPT 系列**：GPT-4o、GPT-4o-mini 等
- **Anthropic 系列**：o1、o3、o4-mini 等
- **Gemini 系列**：Gemini 2.5 Pro、Gemini 2.5 Flash 等
- **自定义模型**：通过配置可以支持其他模型

## 扩展性

LLM 模块设计为高度可扩展：

- **新模型支持**：可以轻松添加对新 LLM 模型的支持
- **自定义功能**：通过混入类可以添加新功能
- **指标扩展**：可以扩展指标收集系统以跟踪其他数据
- **自定义重试逻辑**：可以根据需要自定义重试行为
